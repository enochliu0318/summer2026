flying-dreams.mugee.uk

写给所有抬头看飞机的人

安卓 App 开发

EnglishWorder 背单词

帮一个阿姨开发的背单词软件

一款安卓背单词 App，支持自建单词表、Excel/CSV 批量导入，还接入了词典接口自动补全音标和释义。背后用的是“艾宾浩斯遗忘曲线”的间隔重复算法，安排每个单词该在什么时候再复习一次。

  • 自建单词表 + Excel/CSV 批量导入，支持中英文表头
  • 接入词典 API 自动补全音标、释义，还有真人发音朗读
  • 基于艾宾浩斯遗忘曲线的间隔重复算法，配合每日提醒推送
  • 闯关式复习：选择题、连连看、拼写、消消乐四种玩法

NameFaceAI · 学生人脸记名系统

github.com/ycrrongos/NameFaceAI

面向教室场景的实时人脸识别与考勤系统：用普通摄像头采集画面，本地 InsightFace 推理识别学生，前端实时标注姓名，并可接入 Rokid 眼镜做 AR 展示。

  • 浏览器采集摄像头 → InsightFace 推理（独显 / 集显 / CPU 自动选择）→ SQLite 存储 → React 实时标注
  • 支持学生录入、名牌 OCR、实时识别考勤、考勤表管理
  • 可选 Rokid 眼镜套壳：准星显示姓名；亦可接 LLM 助手生成记忆口诀
